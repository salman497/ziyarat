# Ziyarat Umrah

This site is hosted at **[https://ziyarat-umrah.netlify.app/](https://ziyarat-umrah.netlify.app/)**

Ideal if you're planning to do Umrah. I designed this for my kids as they wanted to know about famous Ziyarat places in Makkah and Madina.

## Features

- 🕋 Information about famous Ziyarat places in Makkah and Madina
- 🔊 English audio feature so your kids can listen and understand more about the famous places in Makkah and Madina
- 📱 Simple, kid-friendly design
